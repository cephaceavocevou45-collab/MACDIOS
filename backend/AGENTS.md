# Projet : gestion pour petits commerçants (Afrique francophone)

## Description
Application de gestion : ventes, stock, dettes clients.
Utilisateurs peu techniques, connexion lente, surtout Android.

## Stack
- Backend : Django + Django REST Framework, JWT, PostgreSQL (SQLite en dev)
- Frontend : React (Vite) + Tailwind CSS, mobile-first
- Dossiers : /backend et /frontend

## Règles
- Code commenté en français, interface en français
- Chaque commerçant ne voit QUE ses propres données
- Montants en FCFA avec séparateur de milliers
- Pas de fonctionnalité en plus de celles demandées
- Après chaque étape : lancer les tests et me montrer le résultat
